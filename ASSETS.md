# Illustration assets

Generated with the built-in `image_gen.imagegen` tool, then copied into this workspace. No original EasyDry logo was available and none was generated. Source PNGs live in `src/assets/illustrations/`; optimized transparent WebP copies are used by the app.

## Shared generation prompt

“Use case: stylized-concept. Asset type: isolated service illustration for a premium laundry app, transparent PNG. [Subject]. Consistent realistic premium 3D product rendering, three-quarter perspective, soft studio lighting, restrained contact shadows, white navy gray and #075DCE blue materials, realistic fabric texture. Compact centered square composition, all objects entirely visible, transparent margins. No text, no logos, no emoji, no characters. Genuinely transparent background.”
